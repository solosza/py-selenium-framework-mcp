# Elegant Solution - Step Back and Rethink

When current approach feels like a band-aid. Forces stepping back with full context.

## Instructions

Review all context from conversation - the problem, attempted solutions, what went wrong.

**Execute:**
```
ELEGANT SOLUTION MODE

Taking a step back...

WHAT WE TRIED:
- [Approach 1]: [Why it was problematic]
- [Approach 2]: [Why it was problematic]

ROOT CAUSE:
[What's the actual underlying issue we're solving?]

KNOWING EVERYTHING NOW:

The elegant solution is:
[Describe the clean approach]

WHY THIS IS BETTER:
- [Reason 1]
- [Reason 2]
- [Reason 3]

TRADE-OFFS:
- [What we give up]
- [What we gain]

IMPLEMENTATION OUTLINE:
1. [Step 1]
2. [Step 2]
3. [Step 3]
```

**HITL:**
```
ELEGANT SOLUTION PROPOSED

1. Implement this approach
2. Discuss further
3. Keep original approach

Select (1-3):
```
